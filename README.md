# TELCO CUSTOMER CHURN ANALYSIS

A Data Analytics and Exploratory Data Analysis (EDA) project focused on understanding customer churn behavior in a telecom company using Python, Pandas, Matplotlib, and Seaborn. The project analyzes customer demographics, contract details, payment methods, internet services, monthly charges, tenure, and support services to identify the major factors influencing customer churn. 

## 📌 Project Objective

The main goal of this project is to:

* Analyze customer churn patterns
* Identify high-risk customer segments
* Discover business insights using EDA
* Support customer retention strategies
* Reduce revenue loss caused by customer churn

## 📊 Dataset Information

* Dataset: Telco Customer Churn Dataset
* Total Records: 7043 customers
* Features: 21 columns
* Target Variable: `Churn` (Yes/No) 

## 🔧 Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Google Colab
* Jupyter Notebook

## 🧹 Data Preprocessing

* Converted `TotalCharges` into numeric datatype
* Handled missing values
* Removed null records
* Converted target column (`Churn`) into binary values
* Performed data validation and cleaning 

## 📈 Exploratory Data Analysis

Performed detailed EDA to analyze:

* Contract Type vs Churn
* Monthly Charges vs Churn
* Tenure vs Churn
* Payment Method vs Churn
* Internet Service vs Churn
* Senior Citizen vs Churn
* Tech Support vs Churn
* Online Security vs Churn
* Correlation Heatmap Analysis 

## 🔍 Key Insights

* Month-to-month customers showed the highest churn
* Higher monthly charges increased churn probability
* Customers with longer tenure were more loyal
* Fiber optic users had higher churn rates
* Customers without tech support or online security were more likely to leave
* Automatic payment users showed better retention

## 💡 Business Impact

The project helps telecom companies identify churn drivers, improve customer retention strategies, optimize service offerings, and make data-driven business decisions to reduce customer loss and improve revenue retention.
